# Negocio

Aplicación Android **Finanzas Definitiva** para contabilidad por partida doble, posición diaria, remesas y estados financieros.

La versión 3 incorpora una Papelera recuperable: permite mover asientos, deshacer, restaurarlos o eliminarlos definitivamente. Los registros en Papelera no se incluyen en los estados financieros.

GitHub Actions compila `Finanzas_Definitiva_Flutter_v3.zip` y publica el APK como artefacto descargable.
